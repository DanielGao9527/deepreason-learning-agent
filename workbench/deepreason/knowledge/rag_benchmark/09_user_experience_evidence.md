# RAG Benchmark: User Experience Evidence
Document id: rag_benchmark_user_experience_evidence.

User experience can be evidence only when it is explicitly provided by the user and recorded with provenance. It can support project-specific constraints, preferences, failure reports, or acceptance criteria. It should not be treated as general scientific proof unless corroborated by external sources.

中文说明：用户经验可以作为项目证据，但需要明确来源和上下文。它适合支撑偏好、失败案例和验收标准，不应单独当作通用科学结论。
