# Template Principles

This template enforces evidence-first reasoning, gated actions, skillized constraints, long-term memory discipline, and minimal changes.

Every key claim should cite an evidence id. Every risky mutation should pass a gate. Every self-evolution event should create a proposal before changing protected assets.

中文说明：这个模板强调证据系统、RAG 搜索结果、状态机门禁、工作流调试、多 Agent 协作、长期记忆提案和最小修改原则。关键结论必须绑定 evidence id，风险动作必须通过 gate。
