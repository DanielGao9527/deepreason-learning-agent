# MVP 学习语料

本轮只覆盖哈希表、二叉搜索树、算法分析和部分选择条件。前三份中文提要由本项目撰写，每份标明对应的 OpenDSA 页面。另从 OpenDSA 官方 GitHub 的固定提交下载三篇原始 `.rst`，保存在 `source/OpenDSA/`，由 `scripts/import_opendsa.py` 校验哈希后转为 `knowledge/04` 至 `06` 三个可检索文本；来源、版本和许可见 `SOURCE_MANIFEST.json`、`source/OpenDSA/MIT-license.txt`。OpenDSA 的项目及许可信息见 https://github.com/OpenDSA/OpenDSA 。

这些文件是可核对的小型教学语料，不是完整“计算机知识数据库”。导入前后的质量应分别评估；新增资料时记录来源、版本、适用范围，并检查是否与现有资料冲突。`knowledge/` 下的 Markdown 和文本会被 DeepReason 现有本地检索器读取。
