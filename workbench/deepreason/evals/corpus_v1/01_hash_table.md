# 哈希表：键、槽位与冲突

来源：OpenDSA, Hashing / HashIntro。原文页面：https://opendsa.cs.vt.edu/ODSA/Books/CS3S26slides/html/Hashing.html
整理方式：本项目为中文学习演示独立撰写的简短提要，不是 OpenDSA 原文复制。

哈希表用哈希函数把键映射到数组槽位。两个不同的键映射到同一槽位，称为哈希冲突；实际实现必须有冲突处理办法。即使两个键不同，也不能假设哈希值必然不同。

哈希表主要支持按键进行精确查找。讨论查找速度时，应说明哈希函数的分布、冲突处理办法和装载情况。不能只写“哈希表永远是常数时间”，也不能把某一种实现的表现推广到全部实现。
