# 第二十四课：把质量与调用代价绑定到同一轮实验

第二十一课的七组回放验证了控制流，第二十二、二十三课把答案空泛与发布契约分开处理。本课补上真实质量对照需要的**实验入口**：先固定条件和采集实际答复，再独立审阅；模型没有提供 token 或人没有填写评分时，不能凭流程通过推算效果。

## 固定什么条件

`scripts/run_learning_experiment.py` 选三个场景：有资料的哈希表/二叉搜索树比较、缺资料的满/完全二叉树比较、哈希冲突概念题。每题在 Skill 未批准/已批准两侧创建独立新工作区，复制相同七文档语料、同一 Workflow Spec，建立相同反馈笔记；只有是否批准固定 Skill 不同。新会话避免上一轮答案污染，语料 SHA-256、工作流哈希、完整 Python 包代码指纹和实验脚本指纹都进入 manifest。两侧使用同一个模型客户端，逐次记录实际 temperature 与 max_tokens；请求模型或服务返回的模型标签变化会中断实验。提供方使用模型别名时，这些标签仍不能证明底层权重版本永远不变。

比较题之外的两题是触发边界控制，不是为了把所有问题强行变成更长回答。执行顺序按题交替先运行 baseline/approved，供诊断顺序影响；三个小样本不构成大规模效果结论，也没有自动变成独立人工标注集。

## 代价怎样记录

`learning_experiment.py` 的 `ExperimentClient` 包住既有模型客户端。每次**转交底层客户端的尝试**记录角色、请求/返回模型标签、采样参数、提示内容哈希、状态与耗时；失败和重试都占实验预算。记录只接收提供方明确返回的非负整数 prompt/completion token，忽略 raw 响应中的其他内容，不落提示词、Key 或错误正文。某次没有 usage 时，总 token 保持 `null`，另报已知部分及完整性；货币成本始终未测，不按字符猜 token 或套未经确认的价格。

实验默认最多转交 32 次，限额在下一次转交前检查。全仓库真实千问的 SQLite 100 次预占上限继续独立执行；二者不能互相替代。脚本模型当前三组两侧合计 16 次；若真实模型选择更多严格路径或出现重试，32 次可能不足，实验应中断并保留失败尝试。计划输出还给出“六轮 × 四角色 × 每角色两次”的宽上界 48 次，**32 是主动限制，不是最坏路径一定足够的承诺**。

不可重试错误会封住后续请求，即使原 Reviewer 捕获异常并返回安全说明，也不能继续发送。每个角色最后一次尝试仍失败时，这一轮属于操作失败，不把该安全说明当成“答案审查正确拒绝”。额度、调用预算或模型配置失败的未完成实验不生成可评分的比较包。仓库预占计数前后值会保留；如果其他进程同时调用，差值可能包含其他任务，因此不能直接充当本实验精确归因的 HTTP 请求数。

## 人怎样复核，旧评分怎样失效

完成的实验生成四类本地产物：`manifest.json` 保存版本与两侧运行记录；`review_packet.json` 给出题目、A/B 答案和合格证据，隐藏 baseline/approved 标签；`review.json` 是待填表；`scorecard.json` 是汇总。审阅者应先看复核包，评判正确性、成立前提、证据是否真正支持答案、应答/止答是否恰当，再填写 `pass/fail/not_applicable`。失败须解释理由；审阅者与 `human/AI-assisted` 方法必须显式声明。脚本不会把 AI 整理的题目要点称为独立人工结论。

评分绑定实验 manifest、整个复核包及每份答案哈希。答案、证据、语料/代码记录、样本 ID 被更换，旧评分不能复用。A/B 的映射按实验 ID 与题 ID 确定，汇总时解盲；不假定 A 总是旧版。每项指标只统计两侧都为 pass/fail 的配对，分别列出已评数量与总题数；空表没有“准确率 0%”，而是未评价、差值 `null`。这些哈希能防止错用版本，不能证明审阅者的判断可靠或身份真实。

本次正常离线三组配对完成，转交 **16** 次脚本请求（route 6、reviewer 6、worker 4），目标 Skill 只进入已批准的比较题 Worker **1** 次，生成 **6** 份待评分答案；usage 未提供，token 与货币成本均未测。将实验限额压到 2，底层仅收到 **2** 次，第三次被拒，实验 `aborted`，没有可评分复核包。新增 **17/17** 定向测试包括模拟 usage/重试/模型变化、评分绑定，以及用假底层客户端走 `--qwen` 分支核对持久预算、403 首次停止和剩余名额不足时不初始化提供方；完整副本 **206/206**。本轮真实千问 **0**，仓库计数仍 **14/100**。

## 复现入口与下一步

从仓库根目录 PowerShell：

```powershell
# 默认只显示计划，不初始化千问或发送请求。
.\.venv\Scripts\python.exe scripts\run_learning_experiment.py

# 跑脚本模型，输出新 artifacts/experiments/skill_<id>/ 目录。
.\.venv\Scripts\python.exe scripts\run_learning_experiment.py --offline

# 填好该目录的 review.json 后汇总；空表也能汇总为未评价。
.\.venv\Scripts\python.exe scripts\run_learning_experiment.py --score artifacts\experiments\skill_<id>\review.json
```
