# 第二十三课：严格题的答案覆盖契约

第二十二课发现一个明确缺口：严格题取得了合格资料，Worker 给出“请回顾资料后自己判断”的空泛答复，最终 Reviewer 仍回 `supported`，结构化引用也真实，于是答复被发布。引用结构只能证明引用来自当前证据，不能证明答案回答了问题。这个缺口适合在**发布边界**做窄范围治理，而不是把离线关键词探针接成通用事实裁判。

## 本轮改动在哪里

学习场景的 `LearningOrchestrator._output_review_requirements` 从用户问题确定一个有界清单。对“哈希表一定比平衡二叉搜索树快吗？比较精确查找和范围查询”，清单要求：直接作答、解释精确查找维度、解释范围查询维度、说明“一定”这一绝对断言的边界。清单来自问题明写的维度；它**不**从模型草稿中反推，避免漏答的草稿自己定义较松验收条件。其他严格学习题至少要求直接作答和解释理由。普通 guided 题、原工作流配置和固定上游均不改变。

Worker 产出草稿且现有 Gate 放行后，原有单次最终 Reviewer 调用收到问题、草稿、合格证据和清单。Reviewer 要返回每个 `point_id` 的 `covered/missing/unsupported`、从草稿复制的 `draft_excerpt`、原有结论与证据引用。程序在 `decide_reviewed_release` 中核对：清单项是否恰好齐全、ID 是否重复、每项是否为 `covered`、摘录是否确实出现在本轮草稿且未重复使用。调用请求带**问题、草稿、清单及合格证据 ID/内容哈希**的上下文哈希，回执必须原样带回；拿旧问题、草稿或资料的审查结果复用会被扣留。既有证据 ID、来源内容哈希和原文摘录核验继续运行。任一结构检查失败，就返回受限说明；Worker 草稿不进入用户答复或近期会话。

这是一条**结构化审查契约**，不是独立语义证明。程序能检查“有没有逐项提交、是否引用了本轮真实文本、是否用了当前版本”，但“这句话是否真的解释了范围查询取舍”仍由 Reviewer 模型判断；它若恶意或错误地把空泛片段标成 `covered`，程序不能保证识破。清单只覆盖用户显式提及的少量维度，也可能扣留正确但 Reviewer 未按格式提交的答案。审查响应预算从原来的 850 提至最多 1200 token，仅严格学习题带清单时使用；真实千问的耗时、token 和误拦率尚未测。

## 正常与失败实验

| 离线情况 | 最终结果 | 关键边界 |
| --- | --- | --- |
| 实质性脚本答案 + 四项完整、真实摘录 + 当前上下文哈希 | `released_model_reviewed` | 可以通过新契约；说明不是无条件止答。 |
| 空泛脚本答案，Reviewer 仍回 `supported`，却未给覆盖清单 | `withheld` / `answer_coverage_contract_failed` | 复现第二十二课的漏答发布缺口，草稿不入会话。 |
| 重复摘录、编造草稿摘录、缺项、标为 `unsupported` | 均 `withheld` | 程序逐项核验，不只信 `coverage_complete=true`。 |
| 内容正确的草稿，但审查回传旧上下文哈希 | `withheld` / `review_context_mismatch` | 审查绑定本轮草稿与清单。 |

更新后的单命令路径验收为 **9/9**：同时保留严格题可发布正例与“`supported` 但覆盖清单缺失”扣稿反例。七组 Skill 批准前后回放仍为 **7/7**、意外控制流差异 **0/7**，其中严格题现在按新契约扣稿。六题答案探针终态 **6/6**、资料锚点 **4/4**；三道 guided 可答题的固定脚本字面要点 **0/3**，一严格题被审查扣留，两道资料不足题止答。这里没有千问答案质量改善数字，本轮真实千问请求为 **0**。完整单测数及示例 Ledger 恢复情况以 `docs/PROJECT_STATUS.md` 最新记录为准。

源码归属：上游多角色编排、现有 Gate 与引用审计继续复用；本项目与 AI 协作新增 `learning.py` 的严格学习题清单钩子、`multiagent.py` 的清单与当前草稿绑定交付、`output_review.py` 的程序核验，以及正常/五类失败测试。没有改固定上游 `references/deepreason-full/`，也没有把此机制扩成任意问题的语义判别器。

从仓库根目录 PowerShell 复现：

```powershell
.\.venv\Scripts\python.exe scripts\verify_learning_paths.py
.\.venv\Scripts\python.exe scripts\eval_learning_answers.py
```

下一步仍需要独立复核题目要点，并在额度可用时用相同语料、模型参数和新会话测真实千问：答对、误拦、错引、调用/token/耗时分别计数。**脚本正反例证明契约执行，不证明学习效果。**
