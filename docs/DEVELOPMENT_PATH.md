# DeepReason Learning Agent 开发路径

更新：2026-10-14。这个路径服务于求职项目的**代码、实验、理解**三重验收。每次只推进一个能复现的工作包；未完成的目标不写作简历成果。固定上游、个人与 AI 协作改动分别见 [`UPSTREAM.md`](../UPSTREAM.md) 和 [`workbench/PROVENANCE.md`](../workbench/PROVENANCE.md)。本地更详细的历史计划在 `docs/NEXT_WORKFLOW.md`。

| 顺序 | 状态 | 下一项实际工作及验收 |
| --- | --- | --- |
| **A. 工作流可达性与有限计划** | **已完成** | 已核对学习场景 14 条声明边中实际观察到 9 条；为显式双主体比较题接入两次定向检索与一次证据汇合。实际检索 query、缺资料止答及坏计划前置拒绝均已离线验证。见[第十六课](lessons/LEARNING_16_REACHABILITY_AND_BOUNDED_PLAN.md)。 |
| **B. 失败状态与有限恢复** | **小范围已完成** | 坏计划、交付失败、模型不可用留脱敏终态；显式双主体比较题只在 Top-K 排满且缺主体时扩大一次本地候选，保持原分数门槛。资料真缺失仍止答；源文件中途变化或补查超时阻断会话与发布。见[第十七课](lessons/LEARNING_17_FAILURE_TERMINALS.md)、[第十八课](lessons/LEARNING_18_BOUNDED_RETRIEVAL_RECOVERY.md)。没有通用 checkpoint 续跑或模型自由重规划。 |

当前比较计划是**确定性的三任务小实验**，附带一个窄范围 Top-K 补查；没有模型自由拆解、通用 DAG 或 checkpoint 续跑。完整副本离线测试以最新[项目状态](PROJECT_STATUS.md)为准，八例离线验收 **8/8**；本轮真实千问调用 **0**，本机预占仍为 **14/100**。同初态三组开关对照只证明夹具上的局部恢复，不证明语义答案准确率；账号额度恢复后仍需真实烟测。
