用户已明确要求继续开发，而且现有功能的缺口必须处理；收口不能仅解释为挑六道演示题通过。首版交付目标为：**围绕树与哈希小型课程资料，支持概念解释、条件比较、证据止答、明确笔记和一次受控教学 Skill 修订的本地学习助手**。工程主线为多角色编排、证据/发布契约、会话与写动作可靠性、受控经验复用。

### 八组问题对应的结束边界

| 工程问题 | 首版要做到哪里 | 明确不宣称的能力 |
| --- | --- | --- |
| 路由/RAG 触发 | 学习场景先检索、风险只升级、有效路线复核；失败明确中断 | 任意意图分类准确率、零检索快答 |
| 规划与拆解 | 现有两侧检索+汇合计划真实执行；依赖/环/步数检查，失败有终态，一次 Top-K 补查 | 通用模型规划器、自动重规划、checkpoint 续跑 |
| 工具执行 | 明确笔记读写的 Schema/Gate、查询重试、持久幂等及未知结果核对通过实际流程 | 任意 MCP 工具、模型自主写入、所有工具的恰好一次执行 |
| 检索质量 | 固定语料/来源；能区分资料缺失、漏召回和资格拦截；保留未改善的留出结果 | Embedding/实体图谱、全学科覆盖、跨语言质量已提升 |
| 审查与发布 | S1.2 后生成的学习答复均经过最终审查，结构/版本不合格扣稿；真实语义独立验收 | 程序证明语义正确、审查模型永不出错 |
| 超时/预算/冲突 | 已有有限模型重试、100 次预占、学习会话互斥、源变化检查和笔记回执串通验证 | 问答请求幂等、通用并行调度、跨机器事务 |
| 记忆/Skill | 近期六轮、历史证据、明确笔记与固定 Skill 各有读写边界；候选审批/回退可演示 | 自动学习者画像、完整四层记忆平台、通用自主进化 |
| 追踪与效果 | 请求能追到阶段/终态/失败与耗时；真实验收和一次配对有原始证据 | 测试数等于准确率、离线脚本等于真实模型效果 |

通用 Planner、MCP、完整分层记忆、并行 Agent 和新 UI 是另行确定范围的后续版本；不因这些未实现而持续拖延首版。**已有功能的阻断缺陷必须修复；未承诺的通用能力必须如实标不支持。** 后续每轮只完成上述一个能验证的工作包，更新状态后进入下一项。
